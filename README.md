The badges are drawn from the `data` branch of this repository, where the
figures are kept. `mimir.json` lists the repositories that are followed. The
Wi24rd products are new, so the figures are small; this is what they look like
from the first day.

## Get your own

This repository is a copy of [Wi24rd Mimir](https://github.com/wi24rd-com/mimir),
made with its installer. Mimir keeps the history GitHub does not: repository
traffic beyond 14 days, and how often each release file was downloaded. It
runs in your own account, and nothing is sent to Wi24rd or to any third party.

Start at [github.com/wi24rd-com/mimir](https://github.com/wi24rd-com/mimir#setup).
